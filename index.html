三步开始创作

  1. 01
    配置中转站

    打开 API 设置，填写接口地址、Key 和模型 ID。若接口是 OpenAI 图片格式，选择 Images API；若通过聊天接口返回图片，选择 Chat Completions。

  2. 02
    描述你的画面

    尽量写清主体、环境、构图、光线和风格。也可以添加参考图，或使用灵感标签快速开始。

  3. 03
    生成与保存

    选择比例和数量后开始生成。点击作品可放大查看，支持下载和收藏。

如果浏览器提示跨域（CORS）错误，需要在中转站允许当前网页来源，或后续增加一个简单的服务端代理。
